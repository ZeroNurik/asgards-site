# asgards-site

Подбор вентиляционных решёток и расчёт воздуховодов по оцифрованным каталогам: Атмосфервент SD / GSD, SCHIBERG КВАДРО, РЭД-ЛУК-MONO, РОВЕН РЩ / РЩБ, скорость и расход воздуха в стандартных сечениях.

Сайт: https://zeronurik.github.io/asgards-site/

## Как устроено

Весь сайт — один файл `index.html`: разметка, стили, скрипты, сканы каталогов и выдержки PDF встроены в него. Сборки нет, GitHub Pages публикует файл из ветки `main` как есть.

## Как внести правку

1. Попросите владельца добавить вас в соавторы (Settings → Collaborators).
2. Дайте своему Claude Code ссылку на этот репозиторий и опишите правку, например: «добавь в index.html раздел с каталогом …».
3. Правка попадает на сайт через 1–2 минуты после того, как изменения окажутся в ветке `main`.

Перед правкой заберите свежую версию (`git pull`), чтобы не затереть чужие изменения. Каждая правка сохраняется в истории репозитория, любую можно откатить.

## Материалы каталогов

Сканы и выдержки каталогов принадлежат их производителям и приведены для справки. Лицензия на них не распространяется.
