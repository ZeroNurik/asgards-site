Как оцифровано

Расход и численные шкалы интерполируются в логарифмических координатах. Кривые NR преобразованы в граничные расходы для каждой площади сечения. Поправки на промежуточную длину интерполируются линейно — это расчётное допущение.

Площадь для метровой решётки: 0,007 м² на щель. Опечатки в таблице над диаграммой не использованы; значения сверены с таблицей характеристик и шкалой F.

Пределы

Базовые шкалы: 50–1000 м³/ч на метр длины, 2–32 Па, дальность 2,5–15 м, NR 20–35. Значения NR за шкалой показаны как неравенства. Для длины менее 1 м поправки к дальности и NR отсутствуют.

Дальность относится к горизонтальной подаче при условиях каталога: H = 3 ± 0,5 м. Расположение, температура струи и комфорт в занятой зоне этим расчётом не проверяются. Площадь принята для активной длины; декоративные глухие участки не учитываются.

Проверка по таблице каталога

18 контрольных точек для 1–4 щелей: максимальное расхождение дальности 2,6%. Для 17 точек внутри шкалы давления — 4,8%. Точка 150 м³/ч, 1 щель попадает чуть выше графической границы 32 Па; таблица даёт 32 Па. Это расхождение графики и таблицы, а не заявленная точность оборудования.

Применение на вытяжке

Производитель рекомендует модель для вытяжки, но таблица содержит параметры приточной струи, а отдельные условия вытяжного испытания не указаны. Расчёт

Расход делится поровну между решётками и по длине щели: q = Q / (n × A). Скорость в щели v = q / (3600 × S), где S — живое сечение на 1 м.п. по таблице. Δp и дальность струи интерполируются линейно по q между соседними точками каталога. Для звуковой мощности принято LwA = LwA₁ + (LwA₂ − LwA₁) × ln(q/q₁) / ln(q₂/q₁) — это расчётное допущение, а не методика производителя. Точные табличные точки показаны без интерполяции.

Ниже 1,0 м/с и выше 3,0 м/с значения не рассчитываются: показывается только граница таблицы.

Шум всей решётки

В каталоге LwA дан на 1 м.п. Для решётки длиной A принято LwA + 10 × lg(A / 1 м) — как сумма одинаковых некоррелированных источников по 1 м. Это допущение; для ответственных помещений уточнить у производителя.

Расчёт

Расход делится поровну между решётками и по длине: q = Q / (n × L), м³/ч на 1 м. Скорость в живом сечении v₀ = q / (3600 × Fo), где Fo — живое сечение на 1 м по таблице. Между соседними точками каталога ΔPп интерполируется степенной зависимостью ΔPп = ΔP₁ × (q / q₁)^k, k = ln(ΔP₂/ΔP₁) / ln(q₂/q₁) — кривая проходит точно через обе точки и сохраняет квадратичный характер сопротивления. Дальнобойность — линейно по q. Уровень шума — LA = LA₁ + (LA₂ − LA₁) × ln(q/q₁) / ln(q₂/q₁); это расчётное допущение, а не методика производителя. Колонки «LA < 20» и «LA ≤ 45» для интерполяции приняты как 20 и 45 дБ(А).

Ниже первой точки (LA < 20 дБ(А)) ΔPп оценивается как ΔP₁ × (q/q₁)², шум и дальнобойность показываются только как граница. Выше последней точки (LA > 45 дБ(А)) значения не рассчитываются.

Сопротивление на 1 м

Удельные потери давления на трение R = λ / d · ρv² / 2, коэффициент трения λ = 0,11 · (Kэ / d + 68 / Re)^0,25 (формула Альтшуля). Для прямоугольного сечения d — эквивалентный по скорости диаметр dэ = 2ab / (a + b). Плотность ρ = 353 / (273,15 + t), вязкость воздуха — по формуле Сазерленда.

Сверка с helpeng при L = 1000 м³/ч: Ø125 — 22,6 м/с и 50,1 Па/м (helpeng: 49,96 Па/м); 100 × 400 — 6,9 м/с и 3,96 Па/м (helpeng: 3,95 Па/м). Разница меньше 0,5 % — из-за округления свойств воздуха.

Формула Альтшуля приведена в справочной литературе по вентиляции (например, «Справочник проектировщика. Вентиляция и кондиционирование воздуха»), но пункт по первоисточнику здесь не сверялся. Допустимые скорости страница не задаёт: диапазон вводит проектировщик по действующим нормам РК для своей системы.

Расчёт

Скорость в живом сечении v = L / (3600 · F), потери давления Δp = ζкл · ρ · v² / 2. Плотность дыма при 300 °C по удельному весу γ = 6 Н/м³: ρ = γ / g = 0,612 кг/м³. Плотность воздуха вводится для расчётной температуры. В каталоге КПЖ-1-ДУ указан для вытяжных каналов; применение на приточной компенсации подтверждайте у завода.

Замечания к каталогу

    Как оцифрованы кривые

    Страницы каталога отсканированы при 300 dpi. Оси откалиброваны по рамке графика и подписям шкал. Точки кривых взяты по максимумам синего цвета на скане: по столбцам на пологих участках и по строкам на крутых. Каждая кривая проверена наложением на исходный график. Конец кривой 5-й ступени совпадает с макс. расходом из таблицы характеристик в пределах ±2 % у всех моделей, кроме 50-25/22.4E. Кривые обрываются там, где на графике каталога начинается штриховая граница: дальше характеристики нет.

    Расчёт рабочей точки

    Сеть задана квадратичной характеристикой P = k · L², k = Pзад / Lзад². Рабочая точка — пересечение этой параболы с кривой ступени. Выбирается наименьшая ступень, при которой расход в рабочей точке не меньше заданного. Мощность, ток и шум — табличные значения для 5-й ступени. Для ступеней 1–4 каталог их не приводит.
